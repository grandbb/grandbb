## Build along

My work is intended for learning, experimentation, and small, focused improvements. Start with a repository's README and tests. If you want to adapt a project, fork it and try your idea; useful fixes and clear bug reports are welcome.

Follow this profile for new examples, or star a repository you want to revisit.

**Testnet prototypes only:** the blockchain projects above are not audited financial products. Use mock or testnet assets.
